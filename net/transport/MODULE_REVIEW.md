# Module review: net/transport

## 1. Рефлексивные тесты фиксируют форму реализации и дают ложную гарантию отсутствия API

- **Проблема и триггер.** Изменение места объявления метода, конструктора или Dagger provider при сохранении поведения ломает структурные проверки. Проверка `transportAggregateDoesNotExposeRawStateMachineAsPublicApi` уже проходит при наличии публичного унаследованного `stateMachine()`: она смотрит только `getDeclaredMethods()`.
- **Источники и владельцы.** [Ошибочная проверка](src/test/java/pro/deta/orion/transport/StateMachineAdapterTestOnlyContractTest.java#L24), [унаследованный accessor](../../core/common-runtime/src/main/java/pro/deta/orion/lifecycle/state/AggregateLifecycleStateMachineAdapter.java#L44), [production-вызов](../../core/bootstrap/src/main/java/pro/deta/orion/component/OrionRuntimeStateMachine.java#L90); [структура providers](src/test/java/pro/deta/orion/transport/OrionTransportModuleTest.java#L22), [структура конструктора](src/test/java/pro/deta/orion/transport/TransportLifecycleStateMachineTest.java#L37). Владельцы: [aggregate](src/main/java/pro/deta/orion/transport/TransportLifecycleStateMachine.java#L25), [DI module](src/main/java/pro/deta/orion/transport/OrionTransportModule.java#L12). Реальная композиция проверяется [bootstrap-тестом](../../core/bootstrap/src/test/java/pro/deta/orion/component/OrionRuntimeModuleTest.java#L262); содержательные проверки охватывают [конфигурацию](src/test/java/pro/deta/orion/transport/OrionTransportModuleTest.java#L53), [старт и статусы](src/test/java/pro/deta/orion/transport/TransportLifecycleStateMachineTest.java#L54), [отключение](src/test/java/pro/deta/orion/transport/TransportLifecycleStateMachineTest.java#L84), [ошибку старта и последующую остановку](src/test/java/pro/deta/orion/transport/TransportLifecycleStateMachineTest.java#L123).
- **Документированное поведение.** [README](../../core/common-runtime/README.md#L261) определяет transport-фазу и дочерние adapters; [локальный @AiRule](src/main/java/pro/deta/orion/transport/TransportLifecycleStateMachine.java#L15) требует композиции через публичный raw `StateMachine`; [bootstrap @AiRule](../../core/bootstrap/src/main/java/pro/deta/orion/component/OrionRuntimeStateMachine.java#L27) закрепляет порядок запуска и остановки. Требования обнаруживать API через reflection не найдено.
- **Контракт.** Обязательны конфигурация, Dagger-композиция, дочерние lifecycle/status и порядок фаз. Публичный raw API дочерних adapters также обязателен. Место объявления метода и точный набор параметров providers/конструктора — детали реализации. Отсутствие публичного `transports.stateMachine()` противоречит действующему production-пути.
- **Минимальное исправление.** Удалить два структурных теста `OrionTransportModuleTest`, `aggregateConstructorTakesAllThreeChildStateMachines`, весь `StateMachineAdapterTestOnlyContractTest` и освободившиеся imports/helpers. Оставшаяся проверка наличия child accessor дублирует прямые production-вызовы при компиляции. Сохранить поведенческие тесты и проверять реальную Dagger-композицию сборкой; production API сохраняется.
- **Альтернативы и последствия.** `getMethods()` обнаружит наследование, но закрепит ошибочное требование удалить используемый bootstrap API. Рефлексивная whitelist продолжит фиксировать форму реализации. Удаление структурных блоков устраняет ложную гарантию, сохраняя содержательное покрытие.
- **Уверенность.** Высокая: метод, наследование, реальный вызов и assertions проверены по текущим исходникам. Сборка и тесты в ходе аудита не запускались.
- **Важность / простота.** Важность средняя: ложная гарантия и препятствие корректным изменениям; runtime-дефект не утверждается. Простота высокая: удаление тестового кода в трёх файлах без изменения lifecycle или DI-контракта.
