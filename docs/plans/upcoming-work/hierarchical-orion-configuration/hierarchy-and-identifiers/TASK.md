# Define Hierarchy and Stable Identifiers

Status: todo

Define the domain boundary and canonical addressing for organizations, teams,
repositories, and principals before extending XML or authorization code.

## Scope

- Require each repository to belong to exactly one team and organization.
- Define normalized identifiers and the canonical `org/team/repo` address.
- Decide stable identity and rename semantics independently from display names.
- Define qualified organization-local user references and root system
  administrator identities.
- Reject ambiguous, escaping, duplicate, or cross-organization references.
