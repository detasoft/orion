# Module review: git/git-client

## 6. Созданный HTTP client не завершается вместе с операцией

- **Проблема и триггер.** При client==null каждый open создаёт HttpClient; failed open и session.close не вызывают shutdown/close клиента. Selector/pool зависят от GC; достижимая closed session удерживает client через responseSupplier. Вечная утечка не утверждается.
- **Источники и владельцы.** [Создание](src/main/java/pro/deta/orion/git/client/GitSmartHttpClientTransport.java#L91), [supplier](src/main/java/pro/deta/orion/git/client/GitSmartHttpClientTransport.java#L219), [close](src/main/java/pro/deta/orion/git/client/GitSmartHttpClientTransport.java#L585), реальный [default API consumer](../../tests/git-engine-orion-adapters/src/main/java/pro/deta/orion/git/workflow/orion/OrionGitEngines.java#L43), [streaming test](src/test/java/pro/deta/orion/git/client/GitSmartHttpClientTransportTest.java#L131), production [GitHubRemoteProfile](../git-sync/src/main/java/pro/deta/orion/git/sync/GitHubRemoteProfile.java#L32) с cleanup только credentials.
- **Документированное поведение.** [Injected client caller-owned](src/main/java/pro/deta/orion/git/client/GitRemoteClientTransport.java#L11), [session.close idempotent/unblocks IO](src/main/java/pro/deta/orion/git/client/GitClientTransportSession.java#L8). [JDK API](https://docs.oracle.com/en/java/javase/21/docs/api/java.net.http/java/net/http/HttpClient.html) предоставляет shutdown; [OpenJDK](https://github.com/openjdk/jdk21u/blob/master/src/java.net.http/share/classes/jdk/internal/net/http/HttpClientImpl.java#L809) без него полагается на facade GC и завершение pending operations.
- **Контракт.** Внутренний per-operation client принадлежит failed-open/session lifetime. Injected client остаётся caller-owned; cancellation сохраняется bounded.
- **Минимальное исправление.** Передать только внутренне созданный client в existing session cleanup; инициировать shutdown на failed-open путях и после stream cancellation при close. Для cancellation предпочесть nonblocking shutdownNow, не блокирующий close внутри watchdog. Проверить observable connection disposal и reuse injected client.
- **Альтернативы и последствия.** Обязательный injected client меняет null/default API и real adapters; новый global owner не нужен. [Bootstrap factory](../git-native-proxy/src/main/java/pro/deta/orion/git/proxy/BootstrapGitTransportFactory.java#L106) уже передаёт и закрывает client и не затронута.
- **Уверенность.** Высокая по отсутствующему lifecycle; накопление ресурсов не воспроизводилось. Production bootstrap impact исключён.
- **Важность / простота.** Важность низкая/средняя: default API/test-adapter и production profile path без текущего runtime orchestration, GC-dependent ресурсы. Простота средняя из-за cancellation/ownership.
