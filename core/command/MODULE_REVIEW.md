# Module review: core/command

## 6. Неоднозначное дополнение создаёт незавершённую суррогатную пару

- **Проблема и триггер.** Для кандидатов `go😀` и `go😁` дополнение `go` вычисляет `go\uD83D`: сравнение UTF-16 `char` останавливается внутри emoji. Некорректная строка записывается в редактор и может попасть в выполнение команды.
- **Источники и владельцы.** [commonPrefix](src/main/java/pro/deta/orion/command/CommandNavigator.java#L343), [результат](src/main/java/pro/deta/orion/command/CommandNavigator.java#L91), [терминал](src/main/java/pro/deta/orion/command/terminal/InteractiveTerminal.java#L299), [редактор](src/main/java/pro/deta/orion/command/terminal/TerminalLineEditor.java#L51). [Unicode-тест](src/test/java/pro/deta/orion/command/CommandNavigatorTest.java#L167) проверяет одного кандидата; имена разрешены [каталогом](../../net/git-transport/src/main/java/pro/deta/orion/transport/git/command/ReadOnlyDomainCommandCatalog.java#L92) и [контрактом views](../../net/git-transport/src/main/java/pro/deta/orion/transport/git/command/read/OperatorDomainViews.java#L124).
- **Документированное поведение.** [Требования терминала](../../docs/plans/tasks/08_interactive-ssh-shell/01_terminal-administration.md#L66) требуют сохранения границ code point/UTF-16 и покрытия supplementary Unicode.
- **Контракт.** Дополнение допустимых строк не должно создавать некорректный Unicode. Сохранить фильтрацию доступных кандидатов, неоднозначность, замену полного токена и координаты курсора.
- **Минимальное исправление.** Сравнивать code points либо исключить обрезку внутри корректной суррогатной пары. Проверить два разных emoji с общей старшей половиной, общий полный emoji перед различающимся суффиксом и передачу результата редактору.
- **Альтернативы и последствия.** Новые типы, нормализация Unicode и смена координат API не нужны. Запрет Unicode сужает поддерживаемый контракт. Общий префикс `go` без расширения корректен.
- **Уверенность.** Высокая в дефекте API и прохождении результата через терминал. Текущий `DefaultOperatorDomainSource` возвращает `Unavailable` для организаций/сессий, а существующие repository names ограничены ASCII; текущий production-источник именно двух emoji-кандидатов не установлен. Runtime-проверки не выполнялись.
- **Важность / простота.** Важность низкая/средняя: повреждение поддерживаемого ввода при ограниченной текущей прикладной достижимости. Простота высокая: локальная логика и содержательные Unicode-тесты.

## 7. Таблицы и подсказки измеряют UTF-16 длину вместо экранной ширины

- **Проблема и триггер.** `TerminalCommandRenderer` и `TerminalDisplay.columns` используют `String.length()` для ширины и отступов. `界界` занимает четыре экранные ячейки при длине два; `e\u0301` — одну при длине два. Колонки расходятся, таблица ошибочно считается помещающейся в терминал.
- **Источники и владельцы.** [Отступы](src/main/java/pro/deta/orion/command/terminal/TerminalCommandRenderer.java#L31), [fits](src/main/java/pro/deta/orion/command/terminal/TerminalCommandRenderer.java#L46), [widths](src/main/java/pro/deta/orion/command/terminal/TerminalCommandRenderer.java#L59), [подсказки](src/main/java/pro/deta/orion/command/terminal/TerminalDisplay.java#L213). Реальные строки поступают из [repositoryRows/defaultHead](../../net/git-transport/src/main/java/pro/deta/orion/transport/git/command/ReadOnlyDomainCommandCatalog.java#L578), [источника](../../net/git-transport/src/main/java/pro/deta/orion/transport/git/command/read/DefaultOperatorDomainSource.java#L35) и [заголовков решений](src/main/java/pro/deta/orion/command/decision/DecisionCommandCatalog.java#L95). [Тесты таблиц](src/test/java/pro/deta/orion/command/terminal/TerminalCommandRendererTest.java#L22) покрывают ASCII и экранирование.
- **Документированное поведение.** [План shell](../../docs/plans/tasks/08_interactive-ssh-shell/TASK.md#L159) требует учитывать ширину терминала. Приглашение уже использует экранную ширину Unicode.
- **Контракт.** Выбор таблицы и отступы должны использовать одну экранную ширину отображаемого текста. Сохранить стабильные `plain`, `terse`, `json`.
- **Минимальное исправление.** Переиспользовать `\X` и [TerminalCellWidth](src/main/java/pro/deta/orion/command/terminal/TerminalCellWidth.java#L64), суммируя ширины grapheme clusters. `width` нельзя вызвать для целой строки: он возвращает максимум внутри одного кластера. Измерять экранированный текст; проверить CJK, combining sequences, emoji и plain fallback при недостаточной ширине.
- **Альтернативы и последствия.** Локальное расширение существующего механизма устраняет две модели ширины. Новая библиотека не нужна. Безусловный plain убирает существующую возможность таблиц.
- **Уверенность.** Высокая по арифметике, пути вывода и текущему механизму Unicode; эмулятор терминала не запускался. Достижимость Unicode в completion ограничена замечанием №6; табличные значения имеют более широкий источник.
- **Важность / простота.** Важность низкая/средняя: неверное отображение допустимых значений. Простота высокая/средняя: два потребителя и один существующий механизм.
